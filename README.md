# 🍳 Telegram-бот-магазин с AI-сервисом «Рецепты по фото»

Автономный Telegram-бот с каталогом цифровых товаров и AI-функцией распознавания продуктов по фотографии. Принимает оплату в рублях через ЮKassa, автоматически выдаёт товары и управляет подписками без участия владельца.

## 📖 О проекте

Бот создан как автономная точка продаж цифровых товаров внутри Telegram: пользователь выбирает товар или пользуется AI-функцией, оплачивает покупку через ЮKassa и мгновенно получает результат — без ручных действий со стороны владельца.

**Название бота:** _будет указано позже_

## ✨ Основные возможности

- 📚 Каталог цифровых PDF-товаров с моментальной автоматической выдачей после оплаты

## 🤖 AI-сервис «Рецепты по фото»

### Бесплатный режим
- Пользователь отправляет фото холодильника/продуктов
- Бот распознаёт продукты через Vision-модель (GPT-4o-mini или аналог)
- Выдаётся **2 рецепта** бесплатно
- Лимит: **2 запроса в день** на пользователя

### PRO-режим (платный)
- **Цена подписки:** 699 ₽/мес.
- Неограниченное количество запросов по фото
- Генерация 3–5 рецептов с пошаговыми инструкциями и временем приготовления
- Выбор диеты: ПП, веган, безглютеновое
- Автопродление подписки с уведомлением за 3 дня до списания

**Альтернатива подписке:** разовая покупка пакета — например, «50 рецептов по фото» за 499 ₽.

## 💳 Оплата

- Приём платежей только в рублях через **ЮKassa**
- Способы оплаты: карты всех банков, СБП, SberPay, Google Pay / Apple Pay
- Telegram Stars **не используются**
- После успешной оплаты бот автоматически:
  - выдаёт PDF-файл, **или**
  - активирует PRO-доступ / подписку

Все выдачи товаров и активации происходят автоматически, без участия владельца бота.

## 🚀 Установка и запуск

> Раздел будет дополнен пошаговой инструкцией по развёртыванию.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/<username>/<repo>.git
cd <repo>

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить переменные окружения
cp .env.example .env

# 4. Запустить бота
python main.py
```

---

## 🔐 Переменные окружения

Создайте файл `.env` на основе `.env.example` и заполните следующие параметры:

```env
TELEGRAM_BOT_TOKEN=
YOOKASSA_SHOP_ID=
YOOKASSA_SECRET_KEY=
OPENAI_API_KEY=
DATABASE_URL=
ADMIN_IDS=
```
